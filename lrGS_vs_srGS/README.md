# lrGS vs. srGS benchmarking 
This repository contains scripts for benchmarking structural variant (SV) callsets generated from long-read genome sequencing (lrGS) data, including 181 PacBio samples and 61 ONT samples, against matched short-read genome sequencing (srGS) data.
